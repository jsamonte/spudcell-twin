# spudcell-twin

## What this is
A stochastic model of plasmid inheritance at division in SpudCell, the
chemically defined synthetic cell from Gaut et al. 2026
(bioRxiv 2026.07.01.735724).

## Scientific question
What fraction of SpudCell daughters inherit a complete set of all seven
plasmids, does independent stochastic partitioning explain the observed
inheritance failure rate, and if not, what mechanism would close the gap?

## Status

## Hard rule on parameters
Every parameter is either (a) cited to the preprint or another paper with the
figure or table named, or (b) explicitly marked FREE. There is no third
category. A number without provenance is a bug, and inventing a plausible
value is the worst thing that can happen in this repo.

## Modeling order
Analytic first, then well-mixed stochastic, then spatial, and only advance when
the simpler model demonstrably cannot answer the question. A Smoldyn model that
reproduces what a binomial calculation already told us is two wasted months.

## Stack
Python 3.11, numpy, scipy, pandas, matplotlib, pytest. Add smoldyn ONLY if the
analytic and well-mixed stages justify it.

## Conventions
- Stochastic results are distributions over at least 1000 replicates with
  bootstrap confidence intervals. Never a single run.
- Seeds set explicitly and recorded in output.
- Every figure regenerated by a script in scripts/.
- results/ holds committed CSV summaries; raw trajectories are gitignored.

## What is already built (2026-10-12)
- `src/inheritance.py` + `tests/test_inheritance.py`: the closed-form
  partitioning maths, 21 tests, every analytic value re-derived by Monte Carlo
  on each run. Shared with `cellfree-mcp`, where it was developed and verified.
- `scripts/analytic_baseline.py`: the branch point. Refuses to run without
  --plasmids and --copy-number, prints the case (A/B/C) once given the
  observed inheritance rate, and stops.
- **Known trap carried over from cellfree-mcp:** bioscrape's
  LineageVolumeSplitter does NOT partition fairly. It draws one
  p ~ U(0.5 - noise/2, 0.5) per division, shared across every species, with
  noise defaulting to 0.5. For seven single-copy plasmids that is 1/512 rather
  than 1/128, a factor of four. Any simulation here must set it explicitly.
